# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps them to the label strings used in this repo.

| Role in the skills | Label here        | Meaning                                  |
| ------------------ | ----------------- | ---------------------------------------- |
| `needs-triage`     | `needs-triage`    | Maintainer needs to evaluate this issue  |
| `needs-info`       | `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent`  | `ready-for-agent` | Fully specified, ready for an AFK agent  |
| `ready-for-human`  | `ready-for-human` | Requires human implementation            |
| `wontfix`          | `wontfix`         | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the label from this table.

Related labels already in use: `blocked` (waiting on a dependency), `backlog` (deferred, no milestone), `priority: high|medium|low` (RICE), `size: small|medium|large`.
